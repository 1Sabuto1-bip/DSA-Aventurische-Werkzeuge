# GitHub-Upload – Meister-Kampfmanager 0.3.0

Dieses Paket ist ein **neues, eigenständiges Projekt**. Es wird nicht in das Repository des Heldenbogens hochgeladen.

1. Auf GitHub ein neues öffentliches Repository mit dem Namen `DSA-Meister-Kampfmanager` erstellen.
2. Den gesamten Inhalt dieses Ordners hochladen und committen.
3. In **Settings → Pages** einstellen:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/docs`
4. Die Veröffentlichung abwarten und im Browser testen:

   `https://1sabuto1-bip.github.io/DSA-Meister-Kampfmanager/?v=030`

5. In Owlbear Rodeo unter **Extensions → Add Extension** installieren:

   `https://1sabuto1-bip.github.io/DSA-Meister-Kampfmanager/manifest.json?v=030`

Der Kampfmanager erkennt Helden, deren Charaktertoken bereits mit dem bestehenden Aventurischen Heldenbogen verbunden wurde. Der Manager überschreibt den Originalheldenbogen nicht.
